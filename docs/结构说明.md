# 输出模式（2 种）

主模式：**纯色区块（regions）** —— 按参考 SVG 逆向出来的配方。

## 1. 纯色区块 `--structure regions`（默认）

```
LANCZOS 放大 2×  →  中位切分量化到 N 色（默认 160）  →  vtracer stacked spline
                 →  每个 fill 颜色吸附回量化色板  →  <g id="regions" fill-rule="evenodd">
```

- **少色**：渐变里过度的中间色被并掉（腮红的色彩演变压平到接近肤色），眼影、发丝描边这类
  强边界因为色差大仍然独立成色；
- **拟合曲线**：边界由 vtracer 的样条拟合产生，是长曲线，不是逐像素折线；
- **空腔**：被后画区域包住的部分自然成为洞（参考 SVG 里 4,684 个洞就是这个结构）；
- **颜色共享**：所有 fill 吸附到同一套色板，和参考 SVG 一样是"一套颜色反复用"。

实测（5t5，源图 900×1600，画布 1800×3200）：

| | 参考 SVG | 本项目 regions |
|---|---|---|
| 路径 | 14,444 | 17,163 |
| 颜色 | 106 | 160 |
| 洞 | 4,684 | 由 stacked 逐层产生 |
| PSNR | 23.52 dB | 22.21 dB |
| 文件 | 20.7 MB | 7.5 MB |
| 耗时 | — | 50 s |

参数：`--palette N` 控制色数（106 更接近参考，160 细节更多）。

### 已知不足

软渐变区域（脸颊、脖颈）会在色阶交界处出现斑驳的小色块：中位切分在 sRGB 里把肤色拆成
粉/紫两组，吸附色板后相邻块交替显现。参考 SVG 没有这个问题，因为它那套描摹器对每块区域
用的是"连续色"处理。下一步可以给每块区域拟合一个双色线性渐变（`<linearGradient>`），
既消掉斑驳，又能把"腮红压平、保留眼影"做得更彻底。

## 2. 保真描摹 `--structure fidelity`

不做颜色合并，放大 2.6× 直接描摹（vtracer 无量化）。路径数很多（十几万），但 PSNR 最高
（`处理对比` 三张图 32.37 / 32.69 / 27.98 dB，参考为 32.84 / 27.85 / 26.07）。

适合"只要还原、后续自己上色"的场合；想直接当成品用，用 `regions`。

## 已移除的旧模式

`stacked`（旧叠放）、`structured`（defs/use 分层）、`flat`（纯 path 分层）、`print-regions`
（打印分块）都还能用 CLI 调用，但界面上不再暴露——按"全力攻克纯色区块"的要求收起了。
